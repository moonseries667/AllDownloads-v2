# 前端页面与交互需求

## 1 开发范围

独立前端工程只与 Java 公共接口通信，使用 [HTTP 接口契约](../contracts/HTTP-API.md)。不直接访问 B 站、Telegram、夸克或 Go，不计算权威下载路径，不以浏览器计时器决定任务成功。

建议基线为 Vue 3、TypeScript、Vite 和 Element Plus，使用稳定版本并锁定依赖。Element Plus 的树、表格、抽屉和通知用于统一交互，页面仍围绕媒体浏览与文件管理组织，不直接套用营销页面模板。需要更换基线时由协调对话一次性决定，避免两个前端实现同时出现。

默认只验证桌面：1280×720、1440×900、1920×1080，以及浏览器 100%、125% 和 150% 缩放下的可用区域。采用系统中文字体、功能性中性色和少量状态色；正文不小于 14px，长正文支持舒适阅读。保留清楚焦点与键盘操作，不用颜色作为唯一状态标识。

前端在 Carbon 开发、构建并用 mock 或隔离后端测试；最终构建产物在 Y7000P 运行，正式浏览器使用场景也在 Y7000P。公共接口使用相对地址及明确的开发代理配置，不写死 Carbon 地址。页面中的本机路径和“打开本机目录”指 Y7000P 运行主机，不是构建电脑。

## 2 导航和页面

| 路由 | 主要内容 |
| --- | --- |
| `/` | B 站、Telegram、夸克入口；少量任务和异常概览 |
| `/bilibili` | 信息来源导航、视频卡片、搜索筛选、多选和下载入口 |
| `/telegram` | 收藏消息流、完整文字与附件展开、手工同步、监控状态 |
| `/quark/cloud` | 分享转存、追更状态、网盘目录与文件选择 |
| `/downloads` | 视频/消息/分享下载实例、可调列宽和部分取消 |
| `/archives` | 归档管理：符合上传资格的队列与上传历史 |
| `/tasks` | 全平台各阶段任务和需要处理的问题 |
| `/settings` | 账号、统一下载根、云端目标及运行设置 |

侧栏用于详情，右上角用于错误通知。工作空间导航使用受可用视口高度约束的独立滚动容器，较矮窗口及缩放下可滚动、键盘到达设置。总览标题区域展示服务和网盘挂载摘要；只有应运行服务的观测全部支持运行状态时显示全部启动，未知、加载、异常、失联和未配置分别表达。挂载与云端归档核验独立。Bilibili 顶部展示账号、刷新与下载/归档摘要，不能由演示数据推定真实状态。下载和归档可以从平台页按当前来源过滤进入，全局页仍然可用。平台间切换保留各自筛选和浏览位置，全局搜索按标题或文件名返回分平台结果。

## 3 B 站页面

来源导航保留收藏夹、合集，并将“用户添加视频”“电影”“番剧”放在“其他”分组下；允许粘贴单条或多条链接，逐条呈现加入成功、重复、无法识别与权限问题。先展示已保存信息，在后台刷新来源，显示刷新时间和失败提示。

视频卡片显示封面、标题、作者、时长和简洁状态，未下载内容同样可以浏览。只有标题在新标签打开原站；卡片其余非交互区域（含封面）加入待下载选择，重复点击不重复加入。复选框、详情和下载按钮独立处理，不向卡片冒泡。多 P、季和集在次级区域展开，不混淆内容层级。

支持标题正序、标题逆序、最新视频、最早视频四种排序，默认最新视频，均由 Java 按全局范围排序。时间只使用实际发布时间，缺失时显示未知；日期使用 Element Plus 主题日历，按上海时区起日包含、止日次日不包含的契约筛选。保留类型和下载状态筛选。跨页选择基于内容 ID，不按当前可见 DOM 行数实现。全选筛选结果必须明确显示实际数量，允许排除项目，筛选变化后不悄悄改变已确认选择。

详情按视频、音频、人工字幕语言、弹幕保存会话选择；多 P、分季番剧和电影语言版本保持各自层级。AI 与类型未判明字幕不可选，未知大小不填零。保存不创建预览或下载，未保存关闭恢复此前选择，明确空选择不能恢复全选。下载前使用后端预览，清单显示标题、具体处理动作与事实状态；标题列可切换正逆序，不重复编辑媒体，不展示相对目录或质量策略，大小缺失则隐藏大小列。用户点击提交才创建下载订单。刷新、详情展开、添加来源均不得调用下载提交接口。

页面分别展示“信息更新时间”“下载状态”“归档状态”。例如视频信息可正常查看、下载已完成、上传等待账号处理，应同时准确表达。没有站内播放和独立的视频播放详情页。

## 4 Telegram 页面

主视图为消息条：时间、文字摘要、附件数量、资源状态。点击三角原位展开完整文字，保持换行和链接，同时列出附件名称、类型、大小和单附件状态；无法获取的值明确为空，不猜文件名或大小。

保留“下载收藏增量”入口。初次运行显示全历史扫描范围及可能产生的媒体下载；运行中的扫描和下载有阶段进度。原有显式启用的收藏监控是独立开关，显示下次检查时间、最近扫描游标对应时间和失败原因。

日期以 `2001.01.01-10.11.12` 的形式显示；正文中的原始日期不强行替换。展示消息时间与下载时间时给出明确标签。

第二部分仅保留“收藏夹”增量下载；移除消息链接下载和资源库入口，旧查询参数进入收藏夹。资格由后端统一判定，列表只显示含音视频的单条消息或完整平台媒体组；纯文字、纯照片、纯文档及照片加文档排除，合格单元的全部实际附件（包括同组照片）保留。正文在原摘要位置展开，不重复呈现一份摘要。监控、取消、补齐服从后端实际能力。

## 5 夸克云盘和下载

夸克页面默认进入云盘视图。顶部为“添加分享转存”，每条分享可见目标夸克目录、最近更新、追更开关和错误。默认动作文案为“转存并维护更新”，不能写成“转存并下载”。

左侧为本应用管理的分享与目录树，右侧为文件表格；提供面包屑、回到上级、名称/类型/大小/更新时间/下载状态、文件和文件夹多选。目录可以懒加载，但选择文件夹表示后端展开完整子树，不限于页面已加载的行。

“是否整批使用同一目录”和开关在同一行。目标仅通过目录选择器指定，根显示“我的云盘”，子项仅显示自身名称；面包屑和当前路径按真实父链组合。支持根/父级导航、分页、空目录与错误恢复。提交每条分享的 targetFolderId 和 targetFolderRevision，路径不作身份。整批转逐条继承当前目标，逐条不同目标切回整批后需重新选择。

下载按钮只处理主动选中的对象。公共清单显示标题、确切事实和动作；标题可正逆序排列，全部大小可靠时保留大小列，未知则隐藏。执行仍使用 `Quark/<分享后缀>/...` 路径，但清单不重复展示相对目录。

本机下载根默认来自统一设置，下载清单可为本批修改目录，经 Java 校验后绑定目标引用；本批目录覆盖不修改全局设置且不进入归档。修改目录或媒体选择后旧预览失效，需要刷新后再提交；夸克目标文件夹选择器只控制网盘转存位置。两个位置必须有不同标签。文件版本在预览后发生变化时，提示重新预览受影响条目，不能自动改选。

下载任务可从夸克页查看或进入全局下载页，但不与追更状态混在一个成功标识中。用户只转存、不下载是正常完整的操作结果。

## 6 任务 状态和通知

条目状态由后端返回，显示中文标签与解释。不要从百分比等于 100 推导成功，也不要把任务提交返回 202 显示为下载完成。显示已确认的进度、速度、字节数或数量；未知总量采用不定进度，不编造预计完成时间。

取消、暂停请求先显示“正在取消/暂停”，直到后端确认。任务详情列出每个阶段、成功事项、失败对象和可用动作。批次展示成功/运行/失败数量，支持仅重试失败阶段。

所有页面共用通知入口。点击弹窗本体仅关闭提示，非成功结果保留在顶部“通知 → 需要关注”；读取或关闭不解决业务问题。后台问题来自持久 GET /issues，刷新后恢复；前端校验和请求错误在当前会话记录。同一故障按稳定标识合并，任务实际恢复后更新对应问题。连接中断时保留已有内容、标明状态可能过期，重新连通后重新查询事实。

首版用轮询更新：有活动任务时约两秒一次，无活动时降低频率；隐藏标签页减频。轮询只读状态，不触发来源扫描、分享转存或任务重试。未来事件推送应作为接口演进，不由前端单方面新增另一套协议。

## 7 归档管理和目录设置

`/archives` 保留原地址，导航和标题为“归档管理”。只调用 Java 的 `/archives` 上传查询，展示已完整下载、冻结策略为 AUTO 且已冻结有效 Drive 目标的项目；下载未完、必要部分取消和本批 NONE 目标都不进入。前端不使用 `/artifacts` 自行筛选代替后台入队资格。待上传、上传中/核验中、需要处理及上传完成足够；没有本机浏览、清理、搬迁或磁盘面板。上传动作只取后端 allowedActions，复用任务接口和 revision；重试不会重新下载。

设置中的本机目录通过 `/directory-selections` 调用运行主机原生对话框，轮询受控结果并读取 DownloadTarget。取消、不可用、超时保留原值；不使用文件上传控件或浏览器文件句柄。纯演示模式明确返回不可用；正常产品中的运行主机是 Y7000P。

“Goole Drive上传目录”按本轮指定文字显示，内部仍为 Google Drive。与夸克复用 DirectoryBrowser 的层级导航和键盘交互，通过各自适配访问独立账号与节点。目录名与父链用于显示，目标用 accountId/folderId/revision；支持根、上级、分页、空态、权限和失效提示，不提供新建或删除云端目录。

两个目录先编辑草稿，再提交 `/settings/validate` 并读取异步校验，只有 VALID 快照可用 `{validationId}` 和草稿原 revision 保存。新设置只改变后续订单默认目标，旧订单与上传冻结目标不变。运行配额在当前目录保存契约中为只读显示，不发送无效修改。

账号页面保留前序登录入口和运行摘要。敏感输入不写入 localStorage、mock 或日志，不读取已有会话文件。原生窗口、真实 Drive 目录与 Java/Go 联调必须在对应环境单独验收。

## 7.1 下载管理的第三部分接入

`/download-projects` 按视频、逻辑收藏消息、分享返回稳定实例，和批次 ID 分开。Bilibili 详情的“查看下载记录”携带 platform/contentId，刷新与返回保留筛选。列表列宽支持拖拽、双击适宽/最小两态、键盘调整，排序仅作用于已加载数据。取消请求携带项目或子项身份、If-Match、幂等键；受理先显示正在取消，保持原清单分母和已完成文件。

## 8 独立开发及交付

前端可用本地 mock 先实现，但 mock 必须依据共同契约，包含未下载、部分完成、来源失败、待登录、磁盘不足、云端待核对和 Go 不可用场景。mock 与真实 HTTP 实现通过同一客户端接口切换；页面不能直接依赖 mock 数据模块。

接入真实 Java 后至少完成 B 站主动下载、Telegram 收藏同步、夸克只转存追更、夸克选择下载及上传失败五条流程。构建通过不能替代界面验收，mock 验收不能替代真实后端验收。

参考：[Element Plus Tree](https://element-plus.org/en-US/component/tree.html)、[Table](https://element-plus.org/en-US/component/table.html)。使用成熟控件减少交互差异；产品行为以本文和共同契约为准。
